FIRST RUN

1. Run setup.bat.
2. Run run.bat.
3. The browser is intentionally visible.
4. Start with one year, e.g.:
   python -m src.main --excel input.xlsx --years 2023 --headed
5. Check logs/download_log.csv.

If the site layout changes, inspect the visible page and adjust choose_year()/discover_pdf_from_current_page() in src/main.py. Do not bypass CAPTCHA or access controls.
